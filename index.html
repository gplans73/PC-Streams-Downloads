Release Notes

Faster movie startup, corrected audio output and improved 4K buffering. Supports the first-generation Fire TV Stick 4K running Fire OS 6. Encrypted IPTV logins, settings, favourites and viewing progress remain saved with your cloud profile.

Very large 4K movie copies can still buffer when the connection cannot keep up. This update improves playback but does not eliminate that connection limit.

Update the TV that already has your IPTV setup and select Account & Sync → Sync now. Then sign in with the same verified account on the new TV. Install over your existing app to keep local data.

Installation Instructions (Fire TV)

  1. Install the Downloader app from the Amazon App Store
  2. Open Downloader and enter the code: 3635825
  3. Download the APK when prompted
  4. Allow installation from unknown sources if prompted
  5. Install and launch PC Streams
  6. Your existing playlists, favourites, and settings will be preserved
